# Publish every verified testing commit

Supersedes [0002](0002-publish-immutable-application-versions.md). Every push to `testing` that passes the native amd64/arm64 build and `just verify` publishes a keyless-signed, attested GHCR index. Publications run one at a time and pushes that queue behind a running one collapse to the newest (one pending run per concurrency group), so an intermediate commit may never be published. Each publication gets an immutable `sha-<commit>` tag and moves `<VERSION>`, its per-architecture tags, and `stable`; there is still no `latest` or `edge` alias. Renovate automerges fsdk-containers junction bumps behind the merge queue's full gate. Everything the junction determines is derived at build or publish time: the application version (`<gs --version>-<packaging revision>`, with only the revision committed in `VERSION`), IJS's ghostpdl source (included from FSDK's ghostscript element), and the FSDK version/ref labels. So a bare bump, even one that moves Ghostscript, is a complete change. Pinning printer containers bought no safety a revert does not: reverting the PR is the rollback, and `podman auto-update` on `stable` delivers fixes without a manual promotion and release tag.
