# Publish every verified testing commit

Supersedes [0002](0002-publish-immutable-application-versions.md). Every push to `testing` that passes the native amd64/arm64 build and `just verify` publishes a keyless-signed, attested GHCR index. Each publication gets an immutable `sha-<commit>` tag and moves `<VERSION>`, its per-architecture tags, and `stable`; there is still no `latest` or `edge` alias. Renovate automerges fsdk-containers junction bumps behind the merge queue's full gate, and the FSDK version/ref labels are derived from the junction at publish time, so a bare bump is a complete change. Pinning printer containers bought no safety a revert does not: reverting the PR is the rollback, and `podman auto-update` on `stable` delivers fixes without a manual promotion and release tag.
