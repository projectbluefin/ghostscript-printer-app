# Use a self-contained FSDK OCI appliance

The OCI build will be a BuildStream project in this repository that consumes freedesktop-sdk components only where their staged payload satisfies the contracts in `ghostscript-printer-app.c`, `Makefile`, `rockcraft.yaml`, `snap/snapcraft.yaml`, and the shared patches. The runtime is an explicitly shell-enabled FSDK appliance lane, not a strict distroless image, because full driver parity requires D-Bus and Avahi beside the Printer Application and requires Python/xz plus shell-based legacy filters. It will still exclude package managers, build tools, and unused artifact domains. This avoids the duplicated Ubuntu/Rockcraft package graph while preserving a practical upstream path.

CUPS has one owner in the runtime graph. Repository-specific changes use BuildStream's recommended downstream-project pattern rather than `config.overrides`: the top-level FSDK junction stages the canonical `patches/cups/` directory as a `local` source, while its project-level `patch_queue` modifies FSDK's private CUPS element to select GnuTLS and apply those files as a CUPS source `patch_queue`. Every transitive FSDK printing component therefore consumes the same patched libraries without this repository taking permanent ownership of CUPS or duplicating patch contents. Application elements depend only on public FSDK elements. A junction update that invalidates the private patch target must fail for explicit review.

Superseded in part (2026-09): the patched printing stack moved to fsdk-containers' shared printing base (`fsdk-containers.bst:printing/base.bst`), which all four projectbluefin printer applications build on. This repository now junctions fsdk-containers at a pinned commit and reaches FSDK only through it; the single-CUPS-owner rule above is unchanged, but its owner is fsdk-containers.
